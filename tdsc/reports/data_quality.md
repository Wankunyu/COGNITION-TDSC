# 外部样本质量检查

检查日期为 2026-09-11，选样依据为 `manifests/external_selection.json` 中的固定版本与样本 ID。检查对象为冻结的 Dice、Click、Patch 各 50 题，以及会议版全部 141 条记录引用的输入。用 Pillow 解码为 RGB 后比较实际像素，外部内部、外部与会议版之间均未发现整图完全重复；去除底部 UI 后也未发现外部同题型重复题图区。

近重复筛查将灰度题图区缩为 32×32，做二维 DCT，取左上 8×8、去除 DC 后以中位数二值化，Hamming 距离不超过 8 的题对只作为目视检查候选。外部 Click 使用 `(0,0,800,560)`，Dice 使用 `(0,0,1000,650)`，Patch 使用 `(0,0,495,495)`；会议版使用对应目标图。跨来源 Dice/Click/Patch 分别检查 550/500/500 对，各外部类内部检查 1,225 对。没有跨来源候选；Dice 的 `sample_0520` 与 `sample_0937` 是唯一内部候选，目视确认仅共享一个面板，并非重复整题。这些操作用于只读检查，没有产出或评测 C 的变换样本。

Dice 的 300 个面板位置对应 156 个素材文件和 156 种实际面板像素，94 个素材重复使用。素材使用次数分布为 62×1、66×2、15×3、6×4、5×5、2×6。213 个题对共享面板，其中 199 对共享一个、14 对共享两个。所有 50 题连接为一个共享素材组。因此报告固定题集的成功数/50；不将其解释为 50 个独立新素材样本，也不基于单一连通组做聚类 bootstrap。

Click 在上方 800×560 区域内屏蔽两题全部目标框的并集（边缘扩 3 px），比较其余像素。118 个题对具有相同背景，共 10 个组，组大小为 8、7、7、6、5、5、4、3、3、2。脚本 `src/tdsc_eval/data_quality.py` 可复现背景分组。没有图标来源 ID，不能声称完成了图标的语义素材去重。

补充检查将外部 Rotation 的 50 张完整输入图与 A/B 全部 316 个不同输入路径的解码 RGB 像素比较，没有包含外部 Rotation 的整图重复组。这个补充检查没有扩展为 Rotation 的近重复筛查。

Rotation 的 50 题根据公开 `base_image` 字段分为 40 个对象组。每题仅使用 `image_1.png`；其他候选图和答案标签不进入模型输入。Patch 没有原照片来源 ID，因此像素筛查未发现重复不能证明全部照片来源独立。最终分析保留这些限制。
